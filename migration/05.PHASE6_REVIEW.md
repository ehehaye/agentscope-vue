## 2. SSE Fixture 回放冒烟

### 2.1 新增脚本

- 文件：[`scripts/fixture-smoke.mjs`](../scripts/fixture-smoke.mjs)
- 作用：在 Node 环境中直接挂载 Vuex `chat` 模块，回放 4 组 SSE fixture，验证状态机闭环。
- 覆盖 fixture：
  - `text-reply.json`：纯文本回复。
  - `thinking-text-reply.json`：thinking 块 + 文本回复。
  - `tool-call-hitl-pending.json`：thinking + tool_call，挂起在 REQUIRE_USER_CONFIRM。
  - `tool-call-full-cycle.json`：thinking + tool_call + HITL confirm + tool_result + 最终文本（74 事件）。

### 2.2 执行结果

```text
✅ textReply: phase=idle, messages=1
✅ thinkingTextReply: phase=idle, messages=1
✅ toolCallHitlPending: phase=streaming, messages=1
✅ toolCallFullCycle: phase=idle, messages=1
```

结论：聊天状态机 `processEvent` 对 4 类核心 SSE 流程的终态处理正确。

## 4. 新版 Vue vs 旧版 React 逐页功能对照

### 4.1 路由对齐表

| React 路由 | Vue 路由 | 状态 | 说明 |
| --- | --- | --- | --- |
| `/` -> `/chat` | `/` -> `/chat` | 对齐 | 均重定向到聊天。 |
| `/chat/:agentId?/:sessionId?/:memberId?` | `/chat` | 差异 | Vue 用 `query.agentId/sessionId`，无 `:memberId` 团队成员工钻取。 |
| `/schedule` | `/schedule` | 对齐 | 日历/列表切换、新建、详情抽屉均存在。 |
| `/channel` | `/channel` | 差异 | 列表+详情布局对应，但创建/编辑表单缺凭据绑定、fallback 模型。 |
| `/credential` | `/credential` | 对齐 | 左列表+右详情、创建/编辑/删除对话框均存在。 |
| `/mcp` / `/mcp/:hubId` | `/mcp` / `/mcp/:hubId` | 差异 | 列表对齐；Hub 详情抽屉内缺安装动作。 |
| `/skill` / `/skill/:hubId` | `/skill` / `/skill/:hubId` | 差异 | 同上。 |
| `/knowledge` / `/knowledge/:kbId` | `/knowledge` / `/knowledge/:kbId` | 对齐 | 子路由一致。 |
| `/setup` | `/setup` | 差异 | React 为全屏入口；Vue 用路由守卫，错误分支较粗。 |
| - | `/dev/markdown`、`/dev/chat` | 新增 | Vue 调试页，React 没有对应页面。 |
| catch-all 缺失 | `*` -> `/` | 差异 | Vue 有兜底重定向。 |

### 4.3 可接受的低优先级差异

- 上传上下文：React `UploadContext` -> Vue Vuex `upload` 模块。
