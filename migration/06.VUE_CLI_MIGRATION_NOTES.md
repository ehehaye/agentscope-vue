# Vue CLI 4 / Tailwind postcss7-compat 迁移记录

> 迁移目标：将构建工具从 Vite 3 迁移到 vue-cli 4（webpack 4），并将 Tailwind CSS 从 v4 降到 `@tailwindcss/postcss7-compat`（Tailwind v2.2 + PostCSS 7）。
>
> **状态更新（2026-09-07）**：迁移主线已全部完成并交付。`pnpm build` / `pnpm dev` 复核通过，收尾清理已提交（Tailwind `tw-` 前缀统一、移除 SSE fixture 回放设施等）。A 类构建/质量遗留项已全部处理或关闭；剩余仅 B 类可选功能 backlog 与待提交的收尾改动。

## 已完成的改动

### 1. 构建工具替换

- 删除 `vite.config.js`、`index.html`。
- 新增 `vue.config.js`、`babel.config.js`、`public/index.html`。
- `package.json`：
  - 移除 `vite`、`vite-plugin-vue2`、`vite-plugin-vue2-svg`、`@tailwindcss/postcss`、`tailwindcss`、`type: "module"`。
  - 新增 `@vue/cli-service@~4.5.19`、`@vue/cli-plugin-babel@~4.5.19`、`less-loader@^7.3.0`、`file-loader@^6.2.0`、`core-js@^3`、`autoprefixer@^9`、`postcss@^7`。
  - 脚本改为 `serve` / `dev` / `build` / `preview`。

### 2. Tailwind 降级

- 新增 `tailwind.config.js`，将原 `index.css` 中的 `@theme inline` 迁移到 `theme.extend`。
- `src/index.css`：
  - `@import 'tailwindcss'` → `@tailwind base; @tailwind components; @tailwind utilities;`
  - 移除 `@custom-variant dark`，使用 Tailwind v2 内置 `darkMode: 'class'`。
  - `@apply border-border outline-ring/50` 改为原始 CSS `border-color: var(--border); outline-color: var(--ring);`（见下方非阻塞项）。
- `postcss.config.js`：插件改为 `@tailwindcss/postcss7-compat` + `autoprefixer`。

### 3. Vue 版本调整

- 原 `vue@2.6.14` 的模板编译器无法解析模板中的 `?.` / `??` 语法。
- 为保证构建通过，将 `vue` 与 `vue-template-compiler` 固定到 `2.7.0`（仍属 Vue 2 线，vue-cli 4 完全兼容）。
- 移除 `@vue/composition-api` 依赖，改用 Vue 2.7 内置 Composition API：
  - `src/composables/vue.js`、`vue-router.js`、`vuex.js` 改为从 `vue` 导出。
  - 删除 `src/plugins/composition-api.js`。
  - `vue.config.js` 中通过 alias 将残留的业务代码 `import ... from '@vue/composition-api'` 重定向到 `vue`，无需逐文件修改。

### 4. webpack 4 兼容性补丁

- `vue.config.js` 中增加 `configureWebpack.resolve.alias`：
  - `@agentscope-ai/agentscope/event` / `message`：webpack 4 不支持 `package.json` 的 `exports` 字段，手动映射到 `dist/.../index.js`。
  - `htmlparser2`：强制使用 CommonJS 入口 `lib/index.js`，避开 ESM 构建中的 `export * as ...` 语法。
- `babel.config.js` 显式加入 `@babel/plugin-transform-numeric-separator`，因为 webpack 4 的 acorn 不支持 `10_000` 数值分隔符。
- `vue.config.js` 开启 `transpileDependencies: [/.*/]`：大量依赖发布为 ES2020+/ESM，webpack 4 默认不转译 node_modules。
- 源码中移除数值分隔符：`src/api/health.js`、`src/store/modules/chat.js`。
- `MarkdownRenderer.vue` 中 Vite 的 `?url` 导入改为 webpack 4 的 `require('!!file-loader?esModule=false!...')`。
- `date-fns` 从 `^4.1.0` 降到 `^2.30.0`，避免其 v4 源码中的 `?.` 语法在 webpack 4 下需要转译。
